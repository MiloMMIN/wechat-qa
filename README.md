# 微信公众号私信问答导出助手 (WeChat QA Exporter)

一键自动抓取微信公众平台后台「消息管理 / 私信工作台」的粉丝真实提问与 AI / 号主回复，支持问答配对、多轮对话合并、暂停/继续/取消操作，并导出为规范的 CSV 表格。

---

## 🚀 安装方式

### 方式一：一键在线安装（推荐）

需先在浏览器安装 [Tampermonkey (油猴插件)](https://www.tampermonkey.net/) 或 [ScriptCat (脚本猫)](https://scriptcat.org/)，然后点击下方任一安装链接：

- ⚡ [通过 Fastly / jsDelivr CDN 安装（国内直连推荐）](https://testingcf.jsdelivr.net/gh/MiloMMIN/wechat-qa@master/wechat-qa.user.js)
- 🐙 [通过 GitHub Raw 安装](https://raw.githubusercontent.com/MiloMMIN/wechat-qa/master/wechat-qa.user.js)

### 方式二：手动安装
1. 打开 `wechat-qa.user.js`；
2. 复制代码并粘贴到油猴插件「新建脚本」中保存。

---

## ✨ 核心特性

- **精准 DOM 定位**：原生适配微信公众平台新版私信工作台（`.msg-user-item` 与 `.msg-item-wrapper`）。
- **问答严格配对**：利用 `内容由AI生成` 标记及布局结构，严格分离学生问题（`Q1|`, `Q2|`...）与 AI/号主回复（`A1.1|`, `A1.2|`...）。
- **多轮会话整合**：同一粉丝的多次提问和多条长回复自动归集到同一个单元格，使用 `--` 清晰分隔。
- **人性化控制**：支持抓取过程中随时 **暂停 / 继续** 或 **取消导出**（取消时可自动下载已抓取到的数据）。
- **完整时间解析**：自动将微信相对时间（如“昨天 14:53”、“20:59”）换算为标准精确的 `YYYY-MM-DD HH:mm`。
- **全平台自动更新**：脚本内置 `@updateURL` 与 `@downloadURL`，每次发布新版本后油猴会自动静默更新。
